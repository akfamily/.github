## AKFamily

专注于财经数据与量化投研的开源社区。从获取数据到回测与实盘，提供一套开源免费的 Python 工具链。

主页：<https://akfamily.xyz>

```
AKShare（获取财经数据） → AKTools（HTTP API 与 MCP 服务） → AKQuant（量化回测与实盘）
```

## 开源项目

| 项目 | 简介 | 文档 | 安装 |
| --- | --- | --- | --- |
| [**AKShare**](https://github.com/akfamily/akshare) | 开源财经数据接口库，覆盖股票、期货、期权、基金、外汇、债券、指数、加密货币和宏观经济数据，一行代码返回 pandas DataFrame | [akshare.akfamily.xyz](https://akshare.akfamily.xyz) | `pip install akshare` |
| [**AKQuant**](https://github.com/akfamily/akquant) | 基于 Rust 和 Python 的高性能量化投研框架，覆盖从回测到实盘的完整流程 | [akquant.akfamily.xyz](https://akquant.akfamily.xyz) | `pip install akquant` |
| [**AKTools**](https://github.com/akfamily/aktools) | AKShare 的 HTTP API 与 MCP 服务，任何编程语言或 Claude、Cursor 等 AI 助手都能获取数据 | [aktools.akfamily.xyz](https://aktools.akfamily.xyz) | `pip install aktools` |
| [**Awesome-data**](https://github.com/akfamily/awesome-data) | 金融与经济数据工具和数据源合集 | — | — |
| [**AKBroker**](https://github.com/akfamily/akbroker) | 利用 PyBroker 进行量化投资的中文教程 | [akbroker.akfamily.xyz](https://akbroker.akfamily.xyz) | — |

## 社区与服务

- 实盘交易：证券与期货实盘服务，详见 [AKShare 文档 · 实盘交易](https://akshare.akfamily.xyz/trade.html)
- 视频课程、微信公众号【数据科学实战】、知识星球和商务合作：见 [akfamily.xyz](https://akfamily.xyz/#community)

---

AKFamily is an open-source community for financial data and quantitative research: [AKShare](https://github.com/akfamily/akshare) (financial data), [AKTools](https://github.com/akfamily/aktools) (HTTP API and MCP server), and [AKQuant](https://github.com/akfamily/akquant) (backtesting and live trading).
